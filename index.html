3ADecoder measure the centre clip, match it to a rig move, write it into the side rules

Drop a client clip (blockout, animatic, previz, or a finished piece) and it gets measured, not guessed at: optical flow per view, split into a common-mode component (the whole rig rotated — a pan) and a differential component (content spreading outward on the sides — a forward move). That separation is what yields degrees-per-second for a turn and a push rate for a dolly, and it is why the side walls can compensate correctly instead of copying the centre. A still image has no motion to measure — it decodes as hold, and you pick the rig intent yourself.

5Fix left/right mismatch Genjutsu motion transfer, when one side outruns the other

Two independent AI generations, even with identical locked rules, can still come out at slightly different speeds or paths. Pick whichever wall already looks right — the other one gets rebuilt using that wall's actual motion (horizontally mirrored first, since left and right are supposed to move in opposite directions) combined with its own reference image, via Higgsfield's Genjutsu motion-transfer model. Capped at 1080p — Genjutsu's own limit, below 4K if that's your final target; upscale separately afterward if needed.

6Self-calibration measures what it made, re-derives its numbers every 10 generations

Measure set downloads all three finished wall videos, probes each one, and scores the set against the reference numbers taken off a real UE5/nDisplay render: left/right symmetry 1.06 and side-to-centre coupling 0.58. Generated sets measured so far have landed between 0.72 and 1.85 on symmetry, with the sides running roughly an order of magnitude hot relative to the centre's push — those two gaps are what this closes. Every 10 measured generations it re-derives its correction factors from that evidence, damped so one odd batch can't swing the next ten, and clamped so it can never run away. A set that reads as a lens zoom rather than real movement is flagged for a human instead of auto-adjusted — no speed number fixes that.
